**You see:** everything nationally, up to secret.

## Every day

- **Dashboard:** national figures, escalations, coverage compliance,
  critical sites.
- **Acknowledge** escalated incidents.
- Act on critical notifications, including **audit integrity**, **evidence
  integrity** and **unusual exports** alerts.
- **Oversight:** Access requests → Oversight; Administration → Exports review.

## Only you

- **Reference data** (Administration → Reference data): incident types and
  fields, threat types, agencies, sectors, religions, property types. Values
  in use can only be deactivated.
- **Audit log** (Administration → Audit log).

## Rules

- Nobody can change audit records, including you.
- User accounts are managed by the system administrator.
- Everything you view, change, print or export is recorded.
