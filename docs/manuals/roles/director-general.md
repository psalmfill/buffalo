As Director General you see **everything nationally**, up to **secret**.

## Your daily routine

1. **Dashboard:** national figures by state and zone, escalated incidents,
   coverage compliance, critical sites, cross-border activity.
2. **Escalated incidents:** acknowledge and follow them.
3. **Critical notifications:** critical incidents, immediate threats, audit or
   integrity alerts, unusual export activity.
4. **Oversight** of cross-state access (Access requests → Oversight) and of
   exports (Administration → Exports review).

## Responsibilities only you hold

- **Reference data** (Administration → Reference data): incident types and
  their fields, threat types, agencies, sectors, religions and
  denominations, property types. Changes affect every user; values in use can
  only be deactivated. The client's sign-off of the reference data before
  go-live is recorded by the system administrator.
- **Hierarchy** (Administration → Hierarchy), shared with the system
  administrator: state capitals, and the senatorial districts, LGAs and wards
  of every state. Create, rename, deactivate or reactivate them (never delete),
  with your authenticator code and a reason each time. Codes are set when an
  entry is created and never change; the official CSV import remains the source
  of truth.
- **Audit log** (Administration → Audit log): every change and decision in
  BUFFALO ([What is logged and why](../guides/what-is-logged.md)). You are
  alerted if the audit trail's integrity check ever fails.
- **Evidence integrity alerts:** if an evidence file no longer matches its
  fingerprint you are told immediately.

## What you can do

Everything the Deputy Directors General can, nationally.

## What you cannot do

- Manage user accounts or the system (the system administrator does that).
- Change audit records: nobody can.
